## 1. Дублирование логики формирования имени трека

**Важность:** высокая · **Конфликтность:** низкая  
**Категория:** Дублирование кода (DRY)

В методах `play_file` и `duration_changed` повторяется один и тот же блок разбора имени файла. При изменении правил именования придётся править в двух местах, и легко забыть одно из них.

Обычно в проектах такую логику выносят в отдельную функцию:

```python
def _extract_track_name(file_path: str) -> tuple[str, str]:
    """Возвращает (отображаемое имя, имя файла)."""
    file_name = os.path.basename(file_path)
    parts = os.path.splitext(file_name)[0].split('_')
    if len(parts) > 2:
        parts = parts[2:]
    return ' '.join(parts).title(), file_name
```
